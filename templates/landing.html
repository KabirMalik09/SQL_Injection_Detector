Process

How SQLShield Works

01
Input Ingestion & Validation

User input is validated, sanitised, and length-checked (max 2,000 chars). Malformed or empty inputs are rejected before the model is invoked.

02
TF-IDF Vectorisation

The query is transformed using a char-level n-gram TF-IDF vectoriser (n=2–4, 5,000 features) tuned for SQL syntax patterns and obfuscation.

03
Random Forest Classification

The vectorised query passes through a 100-estimator Random Forest trained on 24,734 labelled queries, returning a label and probability vector.

04
Attack Type Classification

A priority-based rule engine classifies SQLi into 9 distinct attack categories for actionable, human-readable threat intelligence.
