API Documentation

REST API reference for the SQLShield AI-powered SQL injection detection service.

Base URL http://127.0.0.1:5000
Single Query Detection
POST /api/predict

Analyses a single SQL query or web input string and returns a classification label, confidence score, and attack type.

Request Body (JSON)
{ "query": "SELECT * FROM users WHERE id = 1 UNION SELECT null, password FROM admin--" }
FieldTypeDescription
querystringRequired. The SQL query or user input to analyse. Max 2000 characters.
Response (200 OK)
{ "id": 1, "query": "SELECT * FROM users WHERE id = 1 UNION SELECT null, password FROM admin--", "label": "SQL Injection", // or "Benign" "confidence": 98.72, // percentage (0–100) "attack_type": "UNION-based", // or "—" for benign "timestamp": "2026-09-09T12:00:00", "response_ms": 4 }
Batch Query Detection
POST /api/predict/batch

Analyse up to 20 queries in a single request. Results are returned in the same order as input.

Request Body (JSON)
{ "queries": [ "SELECT name FROM users WHERE id = 42", "admin' OR '1'='1'--" ] }
FieldTypeDescription
queriesarray[string]Required. List of queries to analyse. Max 20 items, each max 2000 characters.
Response (200 OK)
{ "count": 2, "results": [ { "id": 1, "label": "Benign", "confidence": 97.41, "attack_type": "—", "timestamp": "2026-09-09T12:00:00", "response_ms": 2 }, { "id": 2, "label": "SQL Injection", "confidence": 99.12, "attack_type": "Boolean-based", "response_ms": 1 } ] }
cURL Example
Single Query
curl -X POST http://127.0.0.1:5000/api/predict \ -H "Content-Type: application/json" \ -d '{"query": "admin'\''-- "}'
Batch Query
curl -X POST http://127.0.0.1:5000/api/predict/batch \ -H "Content-Type: application/json" \ -d '{"queries": ["SELECT 1", "1 UNION SELECT null--"]}'
Python requests Example
"""SQLShield API — Python example""" import requests BASE_URL = "http://127.0.0.1:5000" # Single query response = requests.post( f"{BASE_URL}/api/predict", json={"query": "admin' OR '1'='1'--"}, ) result = response.json() print(f"Label: {result['label']} ({result['confidence']}%)") print(f"Attack: {result['attack_type']}") # Batch query batch_response = requests.post( f"{BASE_URL}/api/predict/batch", json={"queries": [ "SELECT * FROM orders WHERE user_id = 7", "1'; DROP TABLE users; --", ]}, ) for r in batch_response.json()["results"]: print(r["label"], r["confidence"])
HTTP Status Codes
CodeMeaningDescription
200OKPrediction returned successfully.
400Bad RequestMissing or invalid input: empty query, non-string, exceeds length limit, or malformed JSON.
429Too Many RequestsRate limit exceeded. Single: 30/min. Batch: 10/min. Global: 200/hour.
503Service UnavailableML model not loaded. Run python train.py to generate model artifacts.
500Internal Server ErrorUnexpected prediction failure. Check server logs.
Error Response Format
{ "error": "Descriptive error message" }
Rate Limiting: All endpoints are rate-limited per IP address. If you exceed limits, wait before retrying. The Retry-After header is not currently returned.
Additional Endpoints
GET /api/models Returns all model metrics and the best model name.
GET /api/history Returns the last 20 detection entries (newest first, in-memory).
DELETE /api/history Clears all in-memory detection history.
